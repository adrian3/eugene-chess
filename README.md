# Eugene

Standalone web/PWA build of Eugene Chess.

## GitHub Pages

Use the repository root `index.html` as the Pages entrypoint.
Live site: [https://adrian3.github.io/eugene/](https://adrian3.github.io/eugene/)

## Notes

- The app uses relative paths for styles, scripts, icons, images, and the manifest.
- External chess-related links are still preserved inside the app.
